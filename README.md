October Amber
=======

Form, List and UI tools for Laravel and [October CMS](https://octobercms.com).

Amber is the widget engine that powers the October CMS admin panel, packaged as a standalone library. It turns YAML configuration into working forms, lists, filters and other backend widgets.

This is the core library. For usage outside October CMS, install the Laravel implementation which brings in this package ready to consume:

**[larajax/amber](https://github.com/larajax/amber)**
