# Flag

Shows a country's flag, from a class named after its two letter code in lower case.

## Basic Usage

```html
<span class="flag-au"></span>
<span class="flag-nz"></span>
<span class="flag-gb"></span>
```

A flag is 4 by 3, as tall as the text around it, so it sizes with the font. Each flag is an SVG loaded only when a page shows it.

Besides the countries, there are `flag-eu` (European Union), `flag-un` (United Nations) and the four nations of the United Kingdom: `flag-gb-eng`, `flag-gb-sct`, `flag-gb-wls` and `flag-gb-nir`.
